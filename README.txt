BookTrack - UI only (no logic yet)

1. Install Visual Studio 2022 with the '.NET desktop development' workload.
2. Open BookTrack.sln.
3. Press F5 to run (opens LoginForm), or double-click any .cs form in Solution Explorer to edit it in the Designer.
4. To preview another screen, change 'new LoginForm()' in Program.cs.

Forms: LoginForm, MainForm, BooksForm, MembersForm, BorrowReturnForm, HistoryForm, StaffForm.
Buttons are not wired yet; event handlers, classes, and MySQL code come next.
